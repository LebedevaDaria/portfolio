# Portfolio V2

Новая версия одностраничного портфолио по bento-макету.

## Процесс работы

### Локальная сборка

После внесения любых изменений нужно собрать проект (запустить сайт) локально.
Для этого все файлы, в которых были сделаны изменения, должны быть сохранены (Ctrl + S).
После этого открываем терминал (Ctrl + ё) и вводим в нём команду: `npm run dev`.
Несколько секунд будет запускаться локальный сервер, затем в терминале отобразится ссылка формата `http://localhost:5173/`.
Нажимаем на неё с зажатой кнопкой Ctrl - локальная версия сайта откроется в браузере.
После проверки обязательно в терминале зажать Ctrl + C, чтобы остановить локальный сервер.

### Отправка изменений в репозиторий Github

Для того, чтобы сохранить свои изменения в репозитории, необходимо выполнить несколько команд Git:
1. `git status` - покажет новые или изменённые файлы в проекте, где неотслеживаемые файлы (не будут добавлены в коммит и отправлены в репозиторий) подсвечены красным;
2. `git add .` - добавляет все неотслеживаемые файлы в новый коммит;
3. `git status` - покажет новые или изменённые файлы в проекте, где отслеживаемые файлы (будут добавлены в коммит и отправлены в репозиторий) подсвечены зелёным;
4. `git commit -m 'Сообщение коммита'` - добавить к новому коммиту сообщение (краткое описание внесённых изменений или задачи, единый стиль сообщений в репозитории, 15-25 символов);
5. `git push` - загрузка коммита в репозиторий.

Описан упрощённый алгоритм, не включающий выбор конкретных файлов и ветки, в которую будут влиты изменения, т.к. это избыточно в рамках небольшого личного проекта.

## Файлы

- `index.html` — разметка страницы
- `styles.css` — весь дизайн и адаптив
- `script.js` — ссылки, sticky-nav и переворот карточек проектов
- `assets/profile/portrait-placeholder.jpg` — временный портрет из макета
- `assets/projects/` — временные изображения проектов, вырезанные из макета

## Как открыть локально

Открой папку `portfolio-v2` в VS Code и запусти `index.html` через Live Server.

## Что заменить своими файлами

В `assets/projects/` можно просто заменить изображения, сохранив имена:

- `analytics-dashboard.jpg`
- `self-service-monitoring.jpg`
- `autograding-system.jpg`
- `team-tracker.jpg`
- `device-grading-robot.jpg`
- `scada-system.jpg`

Для Self-Service Monitoring App и Device Grading Robot Interface уже используется режим `contain` и темная подложка, поэтому прозрачные PNG/WebP тоже подойдут. Если заменишь JPG на PNG/WebP, не забудь поменять расширение в `index.html`.

Портрет: `assets/profile/portrait-placeholder.jpg`.

## Flip-карточки

Стрелка в правом нижнем углу переворачивает карточку. На лицевой стороне — изображение, название и теги; на обратной — название, теги и описание.

Тексты обратных сторон находятся прямо в `index.html`, чтобы их было легко редактировать.

## Контактные ссылки

Все ссылки собраны в начале `script.js` в объекте `PORTFOLIO_LINKS`.
